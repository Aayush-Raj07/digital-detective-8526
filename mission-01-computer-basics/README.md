## 4. My understanding

### Task 1.1 — IPOS: Searching the web

When I type a search query and press Enter, the computer goes through all four IPOS stages:

| Stage | What happens | Hardware involved |
|-------|-------------|-------------------|
| **Input** | I type keywords on the keyboard | Keyboard |
| **Processing** | The CPU runs the browser, formats the network request, and handles the DNS lookup | CPU, RAM |
| **Output** | Search results appear on screen | Display |
| **Storage** | The browser caches pages; the query may be saved in browsing history | SSD |

The keyboard sends key signals to the CPU. The CPU runs the browser software, which contacts a DNS server to find the IP of the search engine. The search engine sends back results. The CPU processes the HTML and the display renders the page. The SSD stores cache data for faster future loads.

### Task 1.2 — Hardware and software

**Hardware:**

| Item | Type | Purpose |
|------|------|---------|
| Keyboard | Input device | Converts key presses into digital signals |
| Display | Output device | Renders text and images for the user to see |
| SSD | Storage device | Stores the OS, apps, and user files permanently |
| CPU | Processing unit | Executes all program instructions |

**Software:**

| Software | Type | Purpose |
|----------|------|---------|
| macOS | Operating system | Manages hardware, runs programs, provides the user interface |
| Safari | Application | Web browser for accessing internet content |
| Terminal | Application | Command-line interface for running shell commands |
| Activity Monitor | Utility | Shows CPU, memory, and disk usage; helps diagnose problems |

### Task 1.3 — Everyday computer systems

| System | Main purpose | One input | One output |
|--------|-------------|-----------|------------|
| ATM | Allow customers to withdraw cash and check balances | Card insertion and PIN entry | Cash dispensed and receipt printed |
| Smart TV | Stream and display video content | Remote control button press | Video and audio displayed on screen |
| Traffic signal controller | Manage vehicle flow at intersections | Road sensor data | Green/yellow/red light signal |

An ATM is a specialised computer: a card reader, keypad, and display serve as input/output devices, and a central processor validates the PIN against bank servers before dispensing cash. A traffic signal controller reads sensor inputs and outputs timed light signals. A smart TV runs an embedded OS, accepts remote input, and renders video output.
