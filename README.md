## Topics Explored

- IPOS model (Input, Processing, Output, Storage)
- Hardware components and software types
- Terminal commands and file management
- Operating system responsibilities, processes, and permissions
- How Python programs run — compiler vs interpreter
- Number systems: binary, decimal, hexadecimal
- Text encoding: ASCII and UTF-8
- Git version control and GitHub collaboration
- Networking: DNS, protocols, packet switching

## Running the Number Converter

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter any positive integer when prompted. The program displays its binary and hexadecimal equivalents.

## Learning Summary

Working through these missions connected theory to practice. Running actual Terminal commands, writing Python scripts, tracking changes with Git, and observing live network lookups made abstract concepts concrete.
